Software Developer

Develop next-gen firmware and software for our innovative Li-Fi communication devices.

About the Role

Join Velmenni’s software team to build firmware and applications that enable cutting-edge Li-Fi communication. Work with embedded systems and collaborate closely with hardware engineers to deliver seamless solutions.

Key Responsibilities:

  • Develop and maintain embedded firmware for Li-Fi devices using C/C++.
  • Write application-level software and tools using Python or similar languages.
  • Collaborate with hardware and testing teams for system integration and debugging.
  • Participate in code reviews, documentation, and continuous improvement.

Required Qualifications:

  • Bachelor’s degree in Computer Science, Electronics, or related field.
  • Strong experience in embedded C/C++ programming.
  • Familiarity with Python and software tools.
  • Understanding of hardware-software interaction.
  • Good problem-solving and communication skills.

Location: Remote

Job Type: Full-Time
